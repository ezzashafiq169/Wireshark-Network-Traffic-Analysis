# Wireshark Network Traffic Analysis

## Overview
A beginner cybersecurity project focused on capturing and analyzing network traffic using Wireshark on Windows 11.

## Tools
- Wireshark
- Windows 11

## What I Analyzed
- DNS queries and IPv4 address lookups
- TCP connections and port numbers
- TCP SYN and SYN-ACK flags
- TCP retransmissions

## Key Learning
Practiced Wireshark display filters and learned how to interpret basic network traffic and TCP connection behavior.

## Evidence

### TCP Traffic Analysis
![Wireshark TCP SYN Analysis](tcp-syn-analysis.png)

### Files
- `network-analysis-report.md` — Summary of the analysis
- `Wireshark-Network-Analysis.pcapng` — Packet capture for further investigation

## Conclusion
This project provided hands-on practice with network traffic analysis and foundational skills relevant to cybersecurity and SOC operations.
